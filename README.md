# Buen Día — Servicios colaborativos

Sitio web de presentación de dos servicios cotidianos, desarrollado para el trabajo colaborativo con Git.

## Servicios
- **Manos al Hogar** — mantenimiento doméstico ligero (Estudiante 1).
- **Mesa Lista** — comida casera por encargo (Estudiante 2).

## Ejecutar
Abre `index.html` en el navegador. No requiere instalación ni compilación.

## Tecnologías
- HTML5 semántico
- CSS3 (Grid, Flexbox, variables y media queries)
- JavaScript (DOM, eventos, menú adaptable y formulario de consulta)
- Google Fonts e imágenes remotas de Unsplash

## Nota
El formulario es una demostración: prepara una consulta mediante `mailto:` y no almacena ni envía datos a un servidor. Sustituye `hola@buendia.example` por un correo real antes de publicar.
