
# Buen Día

**Servicios cotidianos para hacerte la vida más sencilla.**

Buen Día es un sitio web que presenta servicios prácticos para el hogar y la vida diaria. Su objetivo es conectar a las personas con soluciones sencillas para sus necesidades cotidianas.

## Servicios

### Manos al Hogar
Servicio de mantenimiento doméstico ligero que incluye:
- Instalación de repisas, cortineros y accesorios.
- Ajustes de puertas, bisagras y cajones.
- Montaje de muebles.
- Mantenimiento sencillo de elementos domésticos.

### Mesa Lista
Servicio de preparación de comida casera por encargo, pensado para personas que necesitan ahorrar tiempo en sus actividades diarias.

## Tecnologías utilizadas

- HTML5: estructura y contenido de las páginas.
- CSS3: diseño visual y adaptación a diferentes pantallas.
- JavaScript: interacciones y funcionalidades dinámicas.

## Funcionalidades

- Navegación entre las páginas del sitio.
- Menú adaptable para dispositivos móviles.
- Catálogo de servicios con filtros interactivos.
- Formulario para preparar consultas por correo electrónico.
- Desplazamiento suave entre secciones.
- Actualización automática del año en el pie de página.

## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Ejecuta `index.html` en tu navegador.
4. Navega por las páginas para conocer los servicios disponibles.
